## Race commentary (`commentary.m4a`)

No recorded Grand Prix commentary exists under CC0, so these lines are synthesised. The 33 lines were generated by `build/commentary.py` with ElevenLabs text-to-speech (`eleven_multilingual_v2`), using the premade voices Daniel (play-by-play) and George (colour), on the project's ElevenLabs Creator plan. They are bandwidth-limited, lightly compressed and loudness-normalised to -19 LUFS. The ids are in the manifest under `commentary.lines`.

## Files

- `manifest.json`: loop windows and one-shot sprite offsets read by `src/audio.js`.
- `sfx.m4a`: one-shot sprite (stereo). Cue names and offsets are in the manifest.
- `*.m4a` loops: each stream is `[0.1 s tail][loop body][0.1 s head]` of a crossfaded, circularly filtered loop; the manifest gives the loop window so codec padding never reaches the seam.
- `radio.m4a`, `broadcast.m4a`, `crowd_bed.m4a`: team radio sprite, crowd/start-light sprite and grandstand loop; manifest keys `radio`, `broadcast` and `loops.crowd_bed`.
- `build/`: the scripts that produced these files from the sources above (`build.py`, `broadcast.py`).

Rebuild the recorded layers: put the Freesound previews in `<folder>/raw/<id>.mp3`, then run `AUDIO_SRC=<folder> python build/real.py` (motors, loops, `real.m4a` sprite) and `AUDIO_SRC=<folder> ELEVENLABS_API_KEY=... python build/commentary.py`. Both write into `AUDIO_OUT` (default `assets/audio`) and merge `manifest.json`. `build/render.mjs real out.wav` renders the new layers offline (set `PORT` to a local `tools/serve.mjs` port).

Rebuild: put the sources in a folder as `raw/<freesound id>.mp3` and `el/<name>.mp3`, then run `AUDIO_SRC=<folder> python build/build.py`; for the radio and crowd assets put the five-plus Freesound MP3s above in `raw/` and run `AUDIO_SRC=<folder> python build/broadcast.py [bed|broadcast|radio]` on macOS (needs numpy, scipy, soundfile, pyloudnorm and ffmpeg with `aac_at`; swap in `aac` elsewhere). `build/render.mjs <mix|sweep|layers|events|stress> out.wav` renders `src/audio.js` offline in headless Chrome against scripted car states for loudness and peak checks.
